## 🛡️ Filosofia de Engenharia

> *"Segurança não é etapa final. É requisito de engenharia."*
>
> Tratar proteção como etapa pós-entrega é a principal causa de falhas críticas. No meu fluxo de trabalho, cada endpoint é projetado para resistir a sobrecargas, varreduras e abusos antes do deploy em produção.

- 🐧 **Ambiente Nativo Fedora Linux**: Estação e servidores configurados em Fedora Linux, aproveitando o ecossistema Red Hat, políticas avançadas de isolamento, Bash scripting, systemd e hardening de rede.
- ⚡ **Engenharia de Produção & Concorrência**: Backends orientados a I/O não bloqueante com Node.js e Express, automações rápidas em Python e infraestrutura preparada para picos de tráfego sem degradação de resposta.
- 🗄️ **Bancos de Dados Confiáveis**: Modelagem relacional no PostgreSQL com indexação cirúrgica de queries e connection pooling, somado a SQLite3 para persistência embutida rápida e transações ACID.
- 🔒 **Defesa & Infraestrutura**: Administração Linux nativa, automação em Bash, configuração de firewalls (UFW/Iptables/firewalld), rate-limiting por IP e mitigação proativa de vulnerabilidades comuns (OWASP).
- 💎 **Interfaces High-Tech**: Criação de interfaces imersivas sem cara de IA genérica, combinando WebGL com Three.js, animações com GSAP e design system focado em Liquid Glass.
